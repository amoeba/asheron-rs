# asheron-rs

Rust crate and CLI tools for Asheron's Call game data, network protocol, and some structures from ACE. Intended to be used both as a library in other projects and as a general purpose CLI. Uses codegen with messsages.xml and other XML as an input.

Status: Complete enough to use in some projects but not 100% complete. Please file issues if there are things you want to see added.

## Library Usage

List all files in a DAT database:

```rust
use std::fs::File;
use asheron_rs::dat::DatDatabase;

let mut file = File::open("client_portal.dat")?;
let db = DatDatabase::read(&mut file)?;

for entry in db.list_files(true)? {
    println!("0x{:08X}  {:?}", entry.object_id, entry.file_type());
}
```

Read and parse a texture file by object ID:

```rust
use std::fs::File;
use std::io::Cursor;
use asheron_rs::dat::{DatDatabase, DatFile, Texture};
use asheron_rs::dat::reader::{SyncDatFileReader, SyncFileRangeReader};

let mut db_file = File::open("client_portal.dat")?;
let db = DatDatabase::read(&mut db_file)?;

let entry = db.list_files(true)?
    .into_iter()
    .find(|e| e.object_id == 0x06001234)
    .expect("file not found");

let mut range_reader = SyncFileRangeReader::new(File::open("client_portal.dat")?);
let mut reader = SyncDatFileReader::new(
    entry.file_size as usize,
    db.header.block_size as usize,
)?;
let buf = reader.read_file(&mut range_reader, entry.file_offset)?;

let texture: DatFile<Texture> = DatFile::read(&mut Cursor::new(buf))?;
println!("{}x{}", texture.inner.width, texture.inner.height);
```

## CLI Usage

PCAP Parser:

```sh
cargo run --bin pcap --features cli -- <path-to-pcap>
```

DAT CLI:

```sh
cargo run --bin dat --features dat-export,dat-tokio -- <subcommand> [options]
```

Example: Export an icon as a PNG by icon texture ID:

```sh
cargo run --bin dat --features dat-export,dat-tokio -- icon \
  --file client_portal.dat \
  --icon-id 06001234 \
  --output icon.png
```

## Development

The workspace has three crates:

- `crates/asheron-rs` - the core library: protocol parsing, DAT file handling, network packet, and the CLI binaries. Generated by `codegen` crate.
- `crates/codegen` - reads the XML protocol definitions in `ACProtocol/` and generates Rust source code into `asheron-rs/src/generated/`
- `crates/xtask` - a cargo xtask runner; exposes `cargo xtask generate` to invoke codegen

To regenerate the protocol bindings after modifying the XML definitions:

```sh
cargo xtask generate
```

The generated code covers enums, common types, 363 message types (C2S and S2C), 159 game action types, 103 game event types, and Asheron's Call Emulator (ACE) loot enums.

### Testing

Run the full test suite with:

```sh
cargo test --workspace
```

Tests live in `crates/asheron-rs/src/` (unit tests) and `crates/asheron-rs/tests/` (integration tests covering message round-trips and PCAP parsing).
